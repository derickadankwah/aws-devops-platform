# Kestrel Platform

An enterprise-style cloud platform I am building phase by phase while studying DevOps and Cloud Engineering. Kestrel Logistics is a fictional company used as the training scenario; the infrastructure, commands and evidence documented here are my own hands-on work on AWS.

## Principles

- Security from the start: MFA, least privilege, no secrets in this repository
- Cost awareness: tagged resources, budgets, stop or delete what isn't in use
- Evidence-based: every phase documents what was built, how it was verified, and what went wrong
